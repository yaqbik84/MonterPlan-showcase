# MonterPlan by Vemaro

Publiczna prezentacja aplikacji **MonterPlan** — narzędzia Android wspierającego pomiary, montaże i organizację projektów.

**Strona projektu:** https://yaqbik84.github.io/MonterPlan-showcase/  
**Demo Android:** https://appetize.io/app/android/pl.folianawymiar.app?device=pixel7&osVersion=13.0&toolbar=true

## O aplikacji

MonterPlan łączy narzędzia potrzebne podczas pracy terenowej i późniejszego porządkowania danych.

Najważniejsze funkcje:

- kalendarz pomiarów i montaży,
- projekty i terminy,
- kalkulator,
- zdjęcia i notatki,
- eksport danych,
- lokalne rozpoznawanie połączeń,
- ograniczona synchronizacja wybranych pól terminów z PlanerGo,
- podstawowe działanie offline poza synchronizacją.
