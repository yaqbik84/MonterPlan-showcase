# MonterPlan Showcase

Publiczna strona prezentacyjna aplikacji **MonterPlan by Vemaro**.

## Cel repozytorium

To repozytorium zawiera wyłącznie publiczną warstwę prezentacyjną projektu. Pełny kod aplikacji Android pozostaje w prywatnym repozytorium źródłowym.

## Aplikacja

MonterPlan 1.6.1 pomaga w organizacji pomiarów i montaży:

- kalendarz i terminy,
- projekty i dane klienta,
- kalkulator,
- zdjęcia i notatki,
- lokalne rozpoznawanie połączeń,
- eksport danych,
- synchronizacja wybranych pól terminów z Planerem Rodzinnym.

Podstawowe funkcje aplikacji działają lokalnie. Synchronizacja wymaga odpowiedniego połączenia sieciowego/Tailscale.
